# Состояние проекта

Дата обзора: 2026-10-20. База обзора — `origin/main` `8eeee9c`. Это не закрытие AEGIS-ALPHA целиком.

## Сделано

- Sprint 0: FastAPI, JWT и роли `user` / `admin`, PostgreSQL, Redis для rate limit и cache-aside, аудит, Prometheus и Grafana, Docker Compose.
- Сбор дневных котировок отдельным процессом `worker/`: offline и yfinance, проверка строк, карантин, ревизии, дедупликация, отчёты `READY` / `PARTIAL` / `FAILED`.
- Миграция Alembic `20261010_0001` поверх `init.sql`, без удаления рабочих volumes.
- Кэш API восстанавливает `created_at` и `updated_at`. Списки сбрасываются через `SCAN`. Сбой Redis или битый JSON не блокирует чтение из базы.
- `CachedAdapter` при ошибке Redis отдаёт источник, но CLI его не создаёт. Кэш worker не считается подключённым.
- `/results` закрыт JWT, экранирует HTML и показывает не больше 100 записей `items`. Это не экран котировок.
- Read-only API: `GET /api/v1/market/runs`, `GET /api/v1/market/runs/{run_id}`, `GET /api/v1/market/quotes`.
- `/health` — живость процесса. `/ready` — PostgreSQL и Redis API, таймаут 2 секунды, `503` без паролей и URL. Docker перезапускает контейнер по `/health`.
- Контракт времени: обычное закрытие 16:00 America/New_York, раннее 13:00, несессионные даты не пишутся. 31 декабря остаётся полным днём, если 1 января — суббота. Старый штамп раннего закрытия 16:00 переносится на 13:00 с записью в `market_quote_revisions`. Список инструментов — AAPL, MSFT, NVDA, биржа XNAS. `yfinance` закреплён на 0.2.49, потому что 0.2.40 не принимает `multi_level_index`.

## Не закрыто в этом этапе

- Живой Yahoo 2026-10-20 вернул не JSON. Статус проверки: `NOT_VERIFIED`. Подробности в `docs/DATA_STAGE_ACCEPTANCE.md`.
- Календарь не содержит разовых закрытий биржи.
- Разовые закрытия биржи по-прежнему не входят в календарь.
- Пример crontab в `docs/market-operations.md` не установлен и Compose его не вызывает.
- Telegram, файлы, FinBERT и аналитическое ядро не подключены.
- `src/main.py` нельзя запускать вместе с `app/` на одной схеме.
