# Ознакомительный источник MOEX ISS

Адаптер `worker/adapters/moex_adapter.py` делает только GET к официальному ISS.
В этом контуре поддерживаются акции GAZP и GMKN, рынок `stock/shares`, режим
TQBR, дневные свечи `interval=24`. Валюта RUB, идентификатор биржи MISX.
Лот в адаптер не зашит: объём свечи берётся из `volume` без пересчёта в лоты.

Официальные источники:

- [Описание методов ISS](https://iss.moex.com/iss/reference/).
- [Интерфейс и условия использования](https://www.moex.com/a2193).
- Образец адреса: `https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities/GAZP/candles.json`.

Параметры `from` и `till` включают обе даты. Worker принимает `[start, end)`,
поэтому в ISS передаётся `till=end-1 день`. Пагинация использует `start` как
смещение исходных строк и заканчивается только пустой страницей. Повтор
непустой страницы или превышение лимита страниц считается ошибкой, а не
успешной частичной загрузкой. 429, 408, 5xx и транспортные таймауты допускают
ограниченный повтор на уровне общего pipeline; прочие HTTP-ошибки постоянны.

Поля сопоставляются по именам `columns`, не по фиксированным позициям. Цены
JSON разбираются непосредственно в Decimal. Неполные строки, нецелый объём,
неверные OHLC, даты вне окна и конфликтующие свечи передаются в карантин.
Перестановка столбцов не меняет результата.

`quote_time` — стабильная метка дня `23:59:59 Europe/Moscow`, а не фактическое
закрытие торгов. Не применяется календарь США и штамп 16:00 Нью-Йорка.
Поддерживается только `raw`; цены GMKN через дробление не корректируются.
`auto_adjusted` отклоняется до запроса. Это нужно учитывать при последующем
анализе доходностей: скачок цены около корпоративного действия сам по себе
не является рыночным сигналом.

Условия страницы MOEX указывают, что ISS-информация без отдельного договора
предназначена для ознакомления. Применение для извлечения прибыли, иных
целей, а также распространение информации или созданных на ней материалов
и сервисов третьим лицам требует договора с Московской биржей. Текущий
контур ограничен ознакомительной проверкой интеграции; он не предоставляет
прав на последующее коммерческое использование. Реальные выгрузки в git не
включаются. Тесты используют искусственные значения и HTTP MockTransport.

Проверка без сети:

```bash
pytest -q tests/test_moex_adapter.py
```

Запуск выполняется из общего CLI с отдельной исследовательской БД:

```bash
python -m worker collect --provider moex --symbols GAZP,GMKN --start 2024-01-09 --end 2024-01-13 --adjustment raw
```
