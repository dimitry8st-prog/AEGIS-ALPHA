# Finam: исследовательские дневные котировки

Адаптер предоставляет только чтение свечей `GAZP@MISX` и `GMKN@MISX`.
Единственный POST — обмен API secret на короткоживущий access token в
`/v1/sessions`. Методов счетов, заявок и сделок в адаптере нет.

## Проверенный контракт

Официальные источники, проверены 22.10.2026:

- [REST, Auth и Bars](https://api.finam.ru/docs/rest/): JSON `{secret: ...}`
  в POST `/v1/sessions`, ответ `{token: ...}`; GET
  `/v1/instruments/{ticker}@MISX/bars`, `timeframe=TIME_FRAME_D`,
  `interval.start_time` включающий и `interval.end_time` исключающий.
- [Авторизация](https://api.finam.ru/getting-started/bystryy-start/poluchit-access-key-i-uvidet-schet/):
  secret передаётся только в тело Auth, рабочие запросы используют access token.
- [История](https://api.finam.ru/getting-started/bystryy-start/poluchit-kotirovku-i-istoriyu/):
  глубина дневных данных — 365 дней. Разбиение запроса на части не расширяет
  доступную серверную историю.
- [Ошибки и формат Authorization](https://api.finam.ru/getting-started/bystryy-start/diagnostika-oshibok-i-dalneyshie-shagi/):
  REST поддерживает Bearer и сырой access token; адаптер использует Bearer.

Каждый fetch получает новую сессию, без предположения о длительности JWT.
Окно ограничено 365 календарными днями и разбивается на части максимум по 31
дню, максимум 12 запросов Bars. Пустой результат остаётся EMPTY. Ошибки 429,
5xx и сети передаются общей ограниченной retry-политике worker; 400/401/403/404
требуют исправления настроек/доступов. Содержимое ошибок сервера и запрос
авторизации не включаются в сообщения исключений.

Цены берутся как Decimal из объектов `{value: "..."}`, без float; объем должен
быть целым неотрицательным. Поддерживается только `raw`: адаптер не объявляет
серверные данные очищенными от дивидендов или сплитов.

RFC3339 timestamp источника преобразуется к календарной дате Europe/Moscow.
Сохранённое время — метка этой даты 23:59:59 MSK, **не фактическое закрытие биржи**.
Некорректные строки, повторные даты и строки вне запрошенного окна направляются
в карантин с доступными исходными ячейками; секреты и JWT в них редактируются.

## Проверка и доступ

MockTransport-тесты не обращаются к брокеру и не используют реальные реквизиты.
Для проверки живого источника нужен API secret из личного кабинета Finam Trade
API, привязанный к разрешённому счёту и правам на рыночные данные. Его следует
передавать процессу как FINAM_API_TOKEN, не в чат, git или аргументы команды.
При отсутствии токена адаптер до HTTP возвращает `FINAM_NOT_CONFIGURED`.

Работа реальной авторизации и доступность исторических данных для конкретного
токена остаются NOT_VERIFIED до явного live-запуска с локально настроенным
секретом. Mock-тесты не подтверждают существование или доступность счёта.
