# Российский контур AEGIS-ALPHA

Дата проверки: 22.10.2026. База изменения: main `8607c93`, отдельная ветка
`feature/russian-markets-moex-finam`. PR №5 с экспортом снимка не включён:
это независимое изменение поверх уже объединённого сборщика.

## Состав

- Газпром: GAZP, Finam GAZP@MISX.
- Норникель: GMKN, Finam GMKN@MISX.
- MOEX ISS: stock / shares / TQBR, дневные свечи interval=24.
- Российская валюта RUB, Europe/Moscow; идентичность серий различается по provider.
- Конфигурация `config/portfolios/russian-research.json` — исследовательский
  список, без вымышленных позиций, долей и суммы вложений.
- Единственный POST Finam — авторизация. Функций создания/отмены заявок нет.

## Подтверждённые обращения к MOEX

Проверены официальные HTTPS endpoints ISS, с TLS-проверкой:

`/iss/engines/stock/markets/shares/boards/TQBR/securities/{symbol}/candles.json`

Окно `[2024-01-09, 2024-01-13)`:

| Инструмент | Принятые свечи | Карантин | Результат адаптера |
|---|---:|---:|---|
| GAZP | 4 | 0 | OK |
| GMKN | 4 | 0 | OK |

Проверены пагинация до пустой страницы, Decimal OHLCV, MISX, RUB и московская
метка даты `2024-01-09T23:59:59+03:00`. Проверка адаптера использовала
инъекцию транспорта httpx поверх стандартного HTTPS urllib: runtime proxy
имеет схему socks5h, не поддерживаемую закреплённым httpx 0.27.2. Производственный
адаптер сохраняет обычный httpx-клиент и поддержку инъекции транспорта.

Отдельно получена спецификация обоих инструментов из официального ISS:
SECID совпал, BOARDID=TQBR, ISIN GAZP=RU0007661625, GMKN=RU0007288411;
на дату проверки LOTSIZE=10 у обоих. Размер лота не используется для
умножения объёма свечи и не подставляется как количество позиции портфеля.

## Финам

Статус: **NOT_CONFIGURED / NOT_VERIFIED**. В доступном окружении
FINAM_API_TOKEN не настроен. Реальная авторизация не выполнялась; доступ
к счёту, текущим позициям и правам на рыночные данные не заявляется.

29 проверок MockTransport покрывают контракт авторизации/свечей, отсутствие
секрета, 401/403, 429/5xx, таймауты, разделение окна, Decimal и редактирование
секретов в диагностике. Их успех не заменяет live-проверку брокера.

## Проверки

Локально на Python 3.12 выполнены unit/API-проверки; PostgreSQL в этом
окружении отсутствует, интеграционные проверки локально пропущены и должны
быть подтверждены обязательным CI с `REQUIRE_DATABASE=1`.

В CI добавлены проверки российских данных через существующие таблицы:
повтор без новых котировок, карантин с корректным received, защищённое
чтение, фильтр московской даты, отчёт FINAM_NOT_CONFIGURED без HTTP.
Итог CI фиксируется в PR, без смешивания с локальными skipped-проверками.

Деплой и реальные сделки не выполнялись. Существующие американские
провайдеры остаются отдельными сериями. Для российских источников
auto_adjusted не поддерживается: дробления и дивиденды не маскируются.
